## 思路

冒泡排序反复扫描序列，每次比较相邻两元素，若顺序不对就交换，让较大的元素"冒泡"到末尾……

## 复杂度

- 最坏 / 平均：O(n²)
- 最好：O(n)
- 空间：O(1)（原地）

## 参考实现

```cpp
void bubbleSort(vector<int>& a) {
    for (int i = 0; i < a.size(); ++i)
        for (int j = 0; j + 1 < a.size() - i; ++j)
            if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
}
```
